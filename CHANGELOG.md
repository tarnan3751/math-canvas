## 0.6.0 — 2026-11-02

### Notes

- Twenty-five new builtin functions: `det`, `transpose`, `inverse`, `rank`, `rref`, `trace`,
  `linsolve`, `nullspace`, `colspace`, `gramschmidt`, `normalize`, `norm`, `identity`, `zeros`,
  `size`, `charpoly`, `eigenvalues`, `eigenvectors`, `diagonalize`, `lu`, `qr`, `cholesky`,
  `svd`, `lstsq` and `expm` (`det`, `rref` and `eigenvalues` were reserved before). A builtin
  name cannot be defined, so a worksheet or script that defined a function of one of these names
  now gets an error at that definition and should rename it. `M^-1` now evaluates to the inverse.
- The numeric decompositions compute in double precision and mark their values numeric, under
  every number format; the exact linear algebra never does.
- Hipparchus Core 4.0.3 (Apache-2.0; `legal/`) now ships, merged into the runtime image.
- A session saved with vectors on the canvas does not open in 0.5.0 (an unknown object kind);
  every earlier session opens unchanged in 0.6.0.
